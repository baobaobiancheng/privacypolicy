## Affected Pages/Routes

- `/`：项目列表、身份切换和创建入口。
- `/projects/new`：创建地图类项目。
- `/projects/[id]/scope`：四项范围门禁及超范围结果。
- `/projects/[id]/profile`：主体、产品和通用披露信息。
- `/projects/[id]/features`：五组场景选择和手工自定义功能。
- `/projects/[id]/activities/[activityId]`：逐字段事实确认、来源和拒绝影响。
- `/projects/[id]/tasks`：按产品、技术和律师角色查看待办。
- `/projects/[id]/review`：处理活动总览、阻断和风险提示。
- `/projects/[id]/draft`：草稿预览、生成状态和失败重试。
- `/projects/[id]/exports/[snapshotId]`：授权下载 DOCX。

## Key Interactions to Verify

- 开发身份切换后，服务端权限立即变化；生产模式下切换器不存在。
- 候选功能和字段默认未选，客户逐字段确认后才能成为正文事实。
- 修改已确认值后，旧确认、风险判断和当前导出状态同时失效。
- 未知项可创建角色待办，解决后重新确认。
- 页面提示、保存校验和导出阻断使用相同规则代码。
- 一般警告允许带占位符生成；范围停止、导出阻断和冲突禁止生成。
- 重复点击生成复用同一快照，失败后重试仍使用原快照。

## Edge Cases

- 多类别、跨境、多产品和非地图主要功能分别命中范围停止。
- 空产品名称、无已确认活动、缺目的或信息字段分别命中导出阻断。
- 两个标签页同时保存相同字段和不同字段。
- 数据库死锁、连接失败和事务中途异常。
- 内容包缺字段、重复 ID、错误引用、哈希不匹配和旧 schema 无迁移链。
- 精确位置、第三方处理、待定法律依据、事实冲突和缺失披露风险。
- 500 条断言、最大长度文本、20MB DOCX 边界和超过限制。
- DOCX 渲染异常、BLOB 写入失败、最终状态更新失败和进程中断。
- 键盘操作、焦点回到错误字段、移动视口和减少动效偏好。

## Critical Paths

1. 身份切换 → 创建项目 → 通过范围门禁 → 通用披露 → 五组场景 → 自定义功能 → 确认事实 → 总览 → 生成并解析 DOCX。
2. 命中范围停止 → 保存原因 → 导出范围信息，不进入草稿生成。
3. 两标签页修改 → 后提交者收到修订冲突 → 重新载入 → 明确选择后保存。
4. 存在 `DRAFT_WARNING` → 生成带占位符和复核附录的工作草稿。
5. 存在 `EXPORT_BLOCK` 或 `CONFLICT` → 生成被拒绝并定位具体对象。
6. 未授权用户按 ID 猜测读取、修改或下载项目 → 服务端全部拒绝且不泄漏项目信息。
7. DOCX 生成失败 → 快照保留、状态可恢复 → 使用同一幂等键安全重试。

## DOCX Assertions

- 文件可被 ZIP/OOXML 解析。
- 页眉包含“工作草稿，未经律师批准”。
- 正文事实均有关联 assertion 与确认记录。
- 未确认位置使用标准占位符。
- 复核附录包含 clause、assertion、activity、evidence 和内容版本映射。
- `REFERENCE_POLICY` 或未来 `AI_INFERRED` 不能单独成为正文事实。
