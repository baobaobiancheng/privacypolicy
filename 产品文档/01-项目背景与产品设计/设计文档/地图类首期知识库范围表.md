# 地图类首期知识库范围表

确定日期：2026-08-13  
状态：APPROVED  
适用产品：在中国境内提供单一地图导航类 App，不涉及跨境、网约车、支付、社区等第二类别  
维护原则：本地已审核数据优先；客户生成路径不调用付费法律接口

## 一、范围结论

地图类第一期运行时知识包定为：

- 9项直接参与问卷、规则判断和正式政策生成的法规/标准；
- 6项按条件触发或仅供律师内部审查的法规/标准；
- 4组地图类专家和参考产品资料；
- 现有其余法规与案例只作候选资料池，不进入运行时生成。

数量不是准入条件。任何资料只有完成来源核验、条款提取、规则映射和律师审核后，才能进入 `PUBLISHED` 内容包。

## 六、明确排除或仅监控的资料

| 类型 | 首期规则 |
|---|---|
| 征求意见稿 | 不进入正式运行规则；只进入法规变化监控。例如《互联网应用程序个人信息收集使用规定（征求意见稿）》 |
| 尚未实施标准 | 实施前不参与运行时裁决。例如 GB/T 47469-2026 计划于2026-11-01实施，届时由律师评估是否替换或补充现有 App 管理规则 |
| 现有354部其他法规全文 | 保留为候选资料池，不建全量向量索引，不发送模型 |
| LDH全球案例与学说 | 地图类中国境内第一期不自动查询；律师明确需要时单独触发 |
| 网约车、支付、社区、广告经营等专项规则 | 客户确认具有相应主要业务时返回 `OUT_OF_SCOPE`，不在地图类首期继续生成 |
| 跨境规则 | 问卷仅识别是否存在跨境；确认存在即首期阻断，不生成跨境政策 |
| Termly、OneTrust等生成器 | 只可参考产品流程和交互，不作为法律、客户事实或中文政策文本来源 |
| 高德、百度竞品原文 | 不整篇送模型，不直接复制，不向客户展示 |

## 八、验收口径

- 运行时直接知识范围不得超出本表；
- 每个正式规则至少关联一条经过核验的官方条款或标准条目；
- 直接运行资料标题、机关、文号/标准号、时效状态错误数为0；
- 正常地图项目外部法律接口调用数为0；
- 竞品名称出现在客户问题或正式政策中的数量为0；
- 竞品资料单独支撑客户事实或法律结论的数量为0；
- 范围外功能、跨境和第二 App 类别必须在生成前阻断；
- 所有发布级动态问题回答完整后，才允许生成待律师批准的正式文本。
