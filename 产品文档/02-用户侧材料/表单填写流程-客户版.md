# 隐私政策表单填写流程（客户版）

> 本图用于向客户展示“从开始填写到生成隐私政策”的完整流程，不含系统实现细节。

```mermaid
flowchart TD
    Start([开始填写]) --> A[第一步：适用范围确认]
    A -- "四项均满足" --> B[第二步：通用信息披露]
    A -- "任一不满足" --> STOP["暂存并退出<br/>记录暂不适用原因"]

    B --> C[第三步：功能选择<br/>勾选产品实际提供的功能]
    C --> D[第四步：信息选择<br/>确认实际处理的个人信息]
    D --> E[第五步：动态补充问卷]

    E --> E1["系统根据已选功能<br/>自动生成需要回答的问题"]
    E1 --> E2{"逐项回答<br/>有 / 没有 / 不确定"}
    E2 -- "不确定" --> E3["需补充确认后才能继续"]
    E3 --> E1
    E2 -- "有" --> E4["填写具体说明<br/>或使用智能整理"]
    E4 --> E5{"必填内容是否完整"}
    E5 -- "否" --> E4
    E5 -- "是" --> F[第六步：生成政策草稿]

    F --> F1["系统自动编排<br/>政策结构 + 已确认事实"]
    F1 --> F2["生成政策草稿"]
    F2 --> F3["在线预览 / 下载 Word"]
    F3 --> G(["完成<br/>后续可修改并重新生成"])

    B -. "每一步自动保存，随时可离开、稍后继续" .-> H["自动保存"]
    C -.-> H
    D -.-> H
    E -.-> H
    F -.-> J["生成记录保留历史版本<br/>可重新生成或下载"]
```

## 流程要点

1. **适用范围**：先判断产品是否属于地图导航类首期范围；不满足时不会强行生成，可保存后暂存退出。
2. **填写主体信息**：依次填写通用信息、功能、个人信息，系统会按已选功能展示对应的信息项。
3. **动态补充问卷**：不是固定不变的问卷，而是根据“你选了什么功能”自动生成需要确认的问题；回答“有”时可继续填写细节，回答“不确定”会要求补充后才能继续。
4. **自动生成**：所有必填内容确认后，系统自动把政策结构和已确认事实编排成草稿，支持在线预览和下载 Word。
5. **保存与追溯**：每一步自动保存，中途可退出；每次生成结果都会留档，方便修改后重新生成。
