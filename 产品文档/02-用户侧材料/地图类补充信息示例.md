# 地图类隐私政策表单填写示例（方案 F）

> 适用版本：`map-v1.0.0`、知识题库 `map-cn-v1.1.0`、槽位包 `map-slot-v1.0.0`  
> 本文用于演示当前网页的完整填写流程。公司、产品、SDK 和联系方式均为虚构示例，实际使用时必须替换为客户产品的真实情况。

## 如何使用本示例

当前补充流程采用“固定题库 + 智能整理 + 固定字段”的方式：

1. 系统固定决定需要核对哪些主题，DeepSeek 不会自行增加或删除必问题目。
2. 对支持智能整理的主题，先选择“有”，再把本文的“产品情况描述”粘贴到描述框。
3. 点击“智能整理描述”，系统会把描述拆成待核对的字段。
4. 核对预填内容后点击“采用此内容”，也可以直接修改字段；直接手动填写的内容视为已填写。
5. 只有已经填写或采用的固定字段会进入隐私政策生成。原始描述和未采用的候选不会作为正式产品事实。

如果智能整理暂时不可用，直接按本文列出的“固定字段填写值”逐项填写即可，不影响完成流程。

## 第一步：适用范围

四项均选择“是”：

- 只为一个产品生成一份中国境内版隐私政策：是
- 产品以地图、定位或导航为主要功能：是
- 产品不同时属于支付、网约车、社区等其他类别：是
- 产品不涉及向境外提供个人信息：是

示例说明：

> 本政策只适用于“行迹地图”Android 2.4。目前不提供 iOS、网页、小程序或车载版本，不面向中国境外用户，也不涉及个人信息跨境提供。

## 第三步：功能与个人信息

### 1. 定位和导航

选择该功能，并将以下三项均勾选为“处理”：

- 位置信息
- 出发地
- 到达地

处理目的：

> 在用户点击定位、路线规划或开始导航后确定当前位置，计算从出发地到到达地的路线，并提供实时导航服务。

保存期限：

> 实时位置仅在定位或导航期间处理；用户结束导航或主动退出后停止持续获取。为完成用户主动保存的历史路线功能，相关路线记录保存至用户删除或注销账号。

### 2. 实时路况与智能交通

选择该功能，并将以下三项均勾选为“处理”：

- 位置信息
- 道路位置
- 使用时间

处理目的：

> 根据用户当前位置、道路位置、路线方向和使用时间匹配相关道路的实时交通情况，展示拥堵状态并优化路线计算。

保存期限：

> 实时路况请求用于当次路线计算；用于故障排查的请求日志保存 30 日，到期后删除或匿名化。

### 3. 浏览地图、附近与探索

选择该功能，并按产品真实情况勾选：

- 浏览记录：处理
- 点击记录：处理
- 设备信息：处理
- 日志信息：处理

处理目的：

> 展示地点详情、附近服务和最近浏览内容，统计功能使用情况并排查页面加载或接口异常。

保存期限：

> 最近浏览记录在设备本地保存 90 日，用户可随时清除；基础访问日志在服务器保存 30 日后删除或匿名化。

### 4. 客服服务

选择该功能，并按产品真实情况勾选：

- 联系方式：处理
- 账号信息：处理
- 沟通记录：处理
- 问题材料：处理

处理目的：

> 核验反馈人与账号的关联，回复咨询或投诉，并使用用户主动提交的截图、日志等材料定位和处理故障。

保存期限：

> 一般客服记录保存 180 日；涉及投诉或争议的记录按照争议处理的实际需要保存，到期后删除或匿名化。

### 5. 安全保障服务

选择该功能，并按产品真实情况勾选：

- 设备标识符：处理
- 系统版本：处理
- IP 地址：处理
- 崩溃日志：处理

处理目的：

> 识别异常登录、恶意请求和运行故障，保障账号、网络和服务安全，并定位 App 闪退问题。

保存期限：

> 安全日志保存 180 日；崩溃和性能诊断日志保存 90 日，到期后删除或匿名化。

### 6. 表单外自定义功能

本示例不新增自定义功能。真实产品如有“语音导航”“道路事件上报”“家庭位置共享”“停车记录”等功能，应在此处逐项增加，并填写实际处理目的和保存期限。

## 场景四：后台定位

选择：**有**

### 可粘贴到描述框的产品情况

> 只有用户主动点击“开始导航”后，产品才启动持续定位。导航期间，即使 App 切换到后台或设备锁屏，仍会持续获取位置以播报转向和路线偏离提醒；用户结束导航、退出导航页面或关闭定位权限后立即停止。定位频率由导航状态和移动情况动态调整，仅用于持续导航，不用于广告。实时位置不作长期保存；为排查导航异常形成的脱敏定位日志保存 7 日。用户可在导航页点击“结束导航”，或在系统设置中关闭行迹地图的定位权限；关闭后实时导航不可用，但仍可浏览地图和手动查询路线。

### 固定字段填写值

| 固定字段 | 示例填写值 |
| --- | --- |
| 触发条件 | 用户主动点击“开始导航”后启动持续定位 |
| 后台或锁屏行为 | 导航期间切换后台或锁屏后继续获取位置；结束导航、退出导航页面或关闭定位权限后立即停止 |
| 获取频率 | 根据导航状态和设备移动情况动态调整，导航过程中持续或按需获取 |
| 使用目的 | 用于持续导航、转向播报和路线偏离提醒，不用于广告 |
| 保存期限 | 实时位置不长期保存；用于排查导航异常的脱敏定位日志保存 7 日 |
| 关闭入口与影响 | 可在导航页结束导航或在系统设置中关闭定位权限；关闭后实时导航不可用，但仍可浏览地图和手动查询路线 |

如果产品实际上只在前台定位，后台或锁屏后立即停止，应在此题选择“没有”，不要为了测试而选择“有”。

## 完成后的预期结果

完成以上填写后，系统应当：

- 不再显示“需要补充”的阻断项；
- 允许进入草稿生成页面；
- 仅使用已勾选的信息、已填写的处理目的和保存期限、已采用的固定槽位以及其他已明确说明的客户事实；
- 生成结构完整的 Markdown 隐私政策草稿，并支持下载同内容的 Word 文件；
- 不在客户版正文中显示内部字段编号、参考产品来源、模型提示词或未采用的候选内容。

生成结果仍应由客户公司的法务、产品和技术人员共同核对后再对外使用，但系统不会要求进入单独的律师审批流程。
