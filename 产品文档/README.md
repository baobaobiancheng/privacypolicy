# 隐私政策项目产品文档

本目录是交接材料的统一入口。第一次接手项目时，先阅读 [交接文档.md](./交接文档.md)。

## 目录

| 目录 | 内容 | 用途 |
| --- | --- | --- |
| `01-项目背景与产品设计/` | 律师会议结论、产品方案、交互与 UI 规范、工程审核方案、客户演示材料 | 理解产品为什么这样设计 |
| `02-用户侧材料/` | 客户表单填写说明、补充信息示例、已生成文档样例 | 验收用户输入和交付物 |
| `03-竞品隐私政策材料/` | 39 个产品类别、91 个产品目录，包含网页快照、原文、链接页面和提取表 | 类别问卷、固定条款和对标样本的证据池 |
| `04-法规与知识库材料/` | 法规汇编目录、354 部唯一法规的详情结果、检索结果、接口文档和批处理脚本 | 法规检索、知识库建设和数据追溯 |
| `05-律师模板与成品样例/` | 律师提供的政策结构和行迹地图政策样例 | 逐项核对生成结构和固定表述 |
| `98-历史待办/` | 旧版开发待办快照 | 回溯历史决策；不得直接当作当前状态 |
| `99-原始会议记录/` | 原始逐字稿 | 对产品决策和律师观点进行溯源 |

## 数据说明

- 竞品材料已全量纳入：39 类、91 个产品目录、479 个文件。
- `law_detail_results.json` 含 437 条详情记录，按 `lawId` 去重后是 354 部法规。
- 竞品页面和法规数据是研究证据，不等于当前运行时已全部接入生成链路。当前运行逻辑见交接文档。
- 真实 App Key、App Secret、模型密钥、数据库密码均不进入 Git。`04-法规与知识库材料/调用代码/key.md` 已排除，只能使用环境变量或本地忽略文件。
- 本目录纳入所有非敏感业务材料；`.DS_Store`、`__pycache__`、编译缓存、真实凭据和与产品无关的代理工具不属于交接资料。

## 维护规则

1. 新的正式产品文档直接更新本目录，不再在仓库外制造第二份。
2. 原始网页、PDF、Word 和 JSON 保留原文；解读和结论用 Markdown 单独记录。
3. 更新法规或竞品材料时，保留来源、获取日期和提取结果，不覆盖无溯源的人工改写。
