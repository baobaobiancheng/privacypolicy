# 隐私政策文本资料说明

## 目录结构

- 一级目录：`序号_App类别`
- 二级目录：核心代表产品名称
- `隐私政策_官方原文.pdf`或`隐私政策_官方网页快照.html`：有效的官方原始响应；动态空壳页面不再保留
- `隐私政策_文本提取.txt`：能够从网页静态内容中提取到、且仍有留档价值的纯文本
- `隐私政策_完整文本.txt`：浏览器执行页面脚本后提取并通过完整性校验的正文
- `隐私政策_渲染后页面.html`：包含动态加载正文的渲染后页面留档
- `隐私政策_第三方版本监测文本.txt`、`隐私政策_第三方历史留存文本.txt`：官方正文暂时无法直取时保存的辅助文本；不属于官方直接下载件，必须结合来源说明复核
- `来源说明.md`：App Store条目、运营主体、官方政策链接、获取时间、状态及异常说明

## 本轮结果

- 核验记录：92条“类别—核心代表”记录
- 可用官方正文留档：90条，其中44条为浏览器渲染后完整正文、45条为有效静态网页、1条为PDF

- 百度网盘、腾讯新闻均标记为“需官方复核”，不计入上述90条官方正文留档

## 使用提示

1. 同一产品可能因覆盖多个监管类别而分别留档，这是为了保持类别分析链路完整。
2. 安居客已从官网核验正确的隐私政策入口为`id=45`；旧台账中的`id=44`实际是用户服务协议，现已更正。
3. 百度网盘的第三方版本监测文本和腾讯新闻的第三方历史留存文本只用于辅助查找，不应作为“现行官方政策”直接引用。
4. 本目录是2026年7月15日的留档结果。隐私政策会更新，引用时应再次核对官方页面的版本和生效日期。
5. `动态页面补抓结果.json`和`缺失政策补抓结果.json`记录补抓与分级结果；`清理记录.md`记录删除范围。`collect_privacy_policies.py --apply-recovery-results`可将本轮5项结果重新写回台账。
